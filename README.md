# Ivan Jackson | Data Engineer Portfolio

**Live site:** https://dataengineerivan.github.io/

My personal portfolio site, with links to my resume, Tableau dashboards, data engineering projects, and LinkedIn.

## What's on the site

- **About:** opens from the top menu and drops down over the page
- **Link carousel:** four cards that roll every 10 seconds, with a drawing on each card that animates when it reaches the front
- **Skills marquee:** a scrolling strip of the tools I work with
- **Works on any screen:** fits on one screen on laptops and desktops, and switches to a phone layout on mobile

## Built with

Plain HTML, CSS, and JavaScript in a single `index.html` file, with no frameworks or build step. Hosted on GitHub Pages.
